# SkillVerify AI

An anti-hallucination resume tailoring engine powered by local LLMs (Ollama) and deterministic diff auditing.

## Features
- 100% Privacy-First using Ollama (llama3.2:1b)
- Deterministic Python verification engine (verifier.py)
- Smart Skill Reclassification
- Visual Grounding Badges

## Tech Stack
- Python, Flask, Ollama, Llama 3.2, HTML5, CSS3

## How to Run
1. pip install -r requirements.txt
2. ollama run llama3.2:1b
3. python app.py
